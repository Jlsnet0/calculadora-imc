# Calculadora de IMC
Projeto simples, desenvolvido para fins de estudo em HTML, CSS e JavaScript, com o objetivo de praticar manipulação do DOM, fazer validações de dados, uso de funções e lógica de programação.
O programa calcula o Índice de Massa Corporal (IMC) a partir do peso e altura informados pelo usuário e exibe a classificação correpondente.

## Funcionalidades
* Calcular automaticamente o IMC
* Mostrar a classificação:
  * Abaixo do peso
  * Peso normal
  * Sobrepeso
  * Obesidade grau 1, 2 e 3
* Valida os dados
* Mostra o resultado válido ou inválido

## Linguagens utilizadas
* HTML5
* CSS3
* JavaScript
